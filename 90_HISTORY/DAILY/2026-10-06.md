### 디버깅으로 밝힌 근본 버그 3개 (app `d95b983` + migration `20261006000100`)
1. **worker 인증**: worker가 `apikey=anon + Bearer=커스텀 account_lifecycle_worker JWT`로 PostgREST를 호출 → 거부. 프로젝트가 **ES256 비대칭 JWT 서명으로 이전**되어 legacy HS256 커스텀 role 토큰을 수락하지 않음. 이미 정상 동작하는 `process-feedback-notifications`와 동일하게 **`SUPABASE_SERVICE_ROLE_KEY` 재사용**으로 전환(worker가 실제 호출하는 **22개 `account_*` RPC에만** service_role EXECUTE grant — broad grant 금지).
2. **`account-ops-sink` shadowing**: `const URL = Deno.env.get("SUPABASE_URL")`가 전역 `URL` 생성자를 가려 `new URL(req.url)`가 TypeError → `/checkpoint` 500. dispatch는 `claim` 전에 checkpoint 웹훅을 치므로 **전체 파이프라인이 AUTH 이전에서 막혀 아무것도 삭제되지 않았다**. `SB_URL`로 개명하여 해결.
3. **Math FK**: `math_attempts.student_id → profiles`가 **RESTRICT**. ADR-2는 Math 스키마보다 먼저 설계되어 `auth.users`→`profiles` cascade 삭제에 의존하는데, RESTRICT가 profiles 삭제를 막아 GoTrue admin user-delete가 **500 / `AUTH_UNAVAILABLE`**. migration `20261006000100`으로 **RESTRICT→CASCADE** (essay_practice_sessions/student_target_universities와 동일 패턴; profiles 삭제는 계정삭제 때만 발생).

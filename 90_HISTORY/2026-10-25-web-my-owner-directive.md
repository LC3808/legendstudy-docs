==================================================
0. 작업 시작 조건
==================================================

현재 진행 중인 작업:

- 관리자 콘솔 개선
- 논술 회차 단위 첨삭·Credit 정책 복원
- 답안 저장·부분 제출
- 첨삭 결과 UI 개선
- 성장 비교 개선

위 작업을 먼저 안전하게 마무리한다.

현재 작업의 Commit·Push·검증 결과를 확인한 뒤
본 지시서의 작업을 이어서 진행한다.

동일 파일을 동시에 수정하지 않는다.

새로운 평가 엔진을 만들지 않는다.

기존 성공 구현을 재사용한다.

이번 작업은 다음 두 영역을 한 번에 완료한다.

A. 일반 사용자 MY 페이지
B. 나의 논술 LAB 분석·기록 화면

Owner가 이번 작업 완료 후
추가 첨삭 화면 검수를 진행할 예정이다.

- 나의 성장 과정

- 대학 지원 현황

불필요한 설명과 중복 정보를 제거한다.

Flutter APP의 기존 디자인과
WEB의 시각적 일관성을 유지한다.

단, 이번 작업에서는 WEB만 수정한다.

APP 코드는 변경하지 않는다.

3. 나의 프로필 — 상단 히어로
==================================================

기존 APP의 MY 히어로를 참고한다.

상단 프로필 카드에 다음을 표시한다.

- 닉네임
- 이메일
- 현재 상태
- 학교
- 학년

상단에 [프로필 편집] 버튼을 배치한다.

편집 가능한 항목:

- 닉네임
- 현재 상태
- 학교
- 학년

기존 '나의 학교/학년' 별도 섹션은
상단 프로필 히어로로 통합한다.

동일한 정보를 여러 위치에 반복하지 않는다.

설정하지 않은 정보는 빈칸으로 표시한다.

기존 WEB·APP 공통 Backend를 사용한다.

WEB에서 수정한 정보는
APP에서도 동일하게 조회되어야 한다.

기존 프로필 저장 계약을 재사용한다.

4. 용어 통일 — Credit
==================================================

WEB에서 혼재하는
'첨삭권'과 'Credit' 표현을 정리한다.

사용자 노출 명칭은
'크레딧'으로 통일한다.

예:

첨삭권 → 크레딧
첨삭권 구매 → 크레딧 구매
남은 첨삭권 → 남은 크레딧
첨삭권 사용 내역 → 크레딧 사용 내역

내부 DB·API·상품 ID는 변경하지 않는다.

기존 구매·결제·Ledger 계약을 유지한다.

5. 내 이용 현황
==================================================

기존 Credit 잔액과 구매 버튼을 유지한다.

다음 정보를 표시한다.

- 사용 가능한 크레딧
- 무료 크레딧
- 구매 크레딧
- 기타 지급 크레딧
- 만료 예정 크레딧
- 구매·사용 내역

만료 예정 정보는 구체적으로 표시한다.

기존:

만료 예정
2027. 1. 22.
가장 가까운 만료일

변경 예:

2027년 1월 22일 만료
구매 크레딧 2개

실제 만료 대상 Credit 수량과
만료일을 조회하여 표시한다.

만료일만 존재하고
수량을 확인할 수 없는 경우
임의 수치를 표시하지 않는다.

기존 만료 정책을 유지한다.

8. 논술 LAB 성장 시각화
==================================================

현재 단순 숫자 카드만 제공하는
성장 영역을 시각화한다.

기존 실제 저장 데이터를 사용한다.

표시:

- 첨삭 완료 회차
- 재작성 횟수
- 재첨삭 완료 횟수
- 평가요소별 성장 변화
- 최근 첨삭 대학
- 최근 평가 단계

평가요소별 최초·최근 결과를
막대 그래프로 표시한다.

예:

논제 이해 3 → 4
논리적 구성 2 → 4
근거 활용 3 → 3

위 숫자는 UI 설명용 예시다.

실제 화면에서는
저장된 평가 데이터만 사용한다.

서로 다른 평가기준을
임의로 동일 척도로 변환하지 않는다.

성장 데이터가 부족하면
기존 학습 기록을 간결하게 보여준다.

Mock 통계 금지.
